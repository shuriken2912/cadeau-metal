PROJET CADEAU-METAL

Contenu :
- index.html : page web plein écran, fond noir, sans bouton ni texte.
- image-metal.png : illustration affichée après scan du QR code.

Publication sur GitHub Pages :
1. Créer un dépôt public nommé cadeau-metal.
2. Ajouter index.html et image-metal.png à la racine du dépôt.
3. Dans Settings > Pages, choisir Deploy from a branch.
4. Sélectionner la branche main et le dossier /(root), puis enregistrer.
5. Attendre la publication. L'adresse attendue sera :
   https://shuriken2912.github.io/cadeau-metal/

Le QR code sera créé uniquement après vérification que cette adresse fonctionne.
